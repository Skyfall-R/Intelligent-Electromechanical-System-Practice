# 上位机 · 调试控制台

配套协议：`docs/02-调试协议.md` **v3**
配套固件：`firmware/Core/Src/debug_link.c` + `firmware/Core/Src/motion.c`

## 安装

```bash
pip install PySide6 pyqtgraph pyserial
```

PySide6 装不上或报 `DLL load failed` 时，`pip install PyQt5` 也行——程序两种都支持，
优先用 PySide6，失败自动退回 PyQt5，顶栏左上角会显示当前用的是哪个。

## 运行

```bash
python car_console.py            # 正常模式，连蓝牙
python car_console.py --demo     # 演示模式，不接硬件，用假数据看界面
```

## 连接

1. HC-05 配对好（名字 `CAR_DBG`，配对码 `1234`）
2. 顶栏串口下拉里选**「传出」**那个 COM 口（本机是 `COM13`，不是 `COM14`）
3. 波特率 115200 → 点「连接」
4. 连上后会自动发一条 `Q`，主控回 `V` + 全部参数，参数表自动填满

## 键位

**先点「接管遥控」，键盘才生效。**

车只认六个数字动作码，没有速度档——速度由参数 `SPD_TARGET` 决定。

| 键 | 下发 | 动作 |
|---|---|---|
| `W` | `N,01` | 直行 |
| `A` | `N,02` | 左移（横向平移，车头不转） |
| `D` | `N,03` | 右移 |
| `Q` | `N,04` | 左转（原地） |
| `E` | `N,05` | 右转（原地） |
| `S` | `N,00` | 刹车 |
| `空格` | `E` | 急停 |
| `Esc` | `A` | 交还自动 |

**没有「后退」**——同学定的动作集里就没有。要加见 `docs/02-调试协议.md` §5.1.3。

同时按多个键时，以**最后按下**的那个为准（不做合成，因为动作码本身不能叠加）。

遥控面板里「下发 xx」是上位机正在发什么，「固件回报」是主控遥测里报回来的
`cmd_code`。**两个对不上就说明链路或固件有问题**，这是第一个要看的地方。

## 四个曲线页

| 页 | 看什么 |
|---|---|
| **轮速** | 四轮 `cnt_*`（每 12 ms 编码器计数）+ 灰色虚线 = `SPD_TARGET` 目标值 |
| **占空比** | 四轮 PWM 0~100。**顶到 100 还追不上目标 = 负载/电池问题，不是参数问题** |
| **视觉 / 测距** | 视觉方位角、IMU 航向、视觉距离、三路 ToF |
| **指令** | 动作码阶梯图，Y 轴直接标动作名 |

轮速页的单位是**编码器计数，不是 mm/s**。闭环控的就是这个数，和目标线直接对照最省事；
换算成 mm/s 要用 `WHEEL_R_MM` / `ENC_PPR`，这两个还没标定。

## 第一次上车：先验方向表

`motion.c` 里那张四轮方向表**只有「直行」和「右移」有实车旁证**，另外三个是推的。
落地前先把车架空验一遍，十分钟：

1. 四轮悬空，连上，点「接管遥控」
2. 逐个按 W / A / D / Q / E，每个看两件事：
   - 趴下去看四个轮子转向对不对
   - 「轮速」页四条曲线**是不是都为正**
3. 有一条常为负 → 那个轮子的方向符号反了，改 `motion.c` 里 `WHEEL_DIR[]` 对应的格子

**四个符号里错一个，横移就会变成原地打转。**

## 安全

- 松开所有键 → 上位机改发 `N,00`，车刹住但仍在 MANUAL
- 关掉窗口 / 蓝牙断 → **200 ms 内收不到任何 `N` 或 `H`，主控自动刹车**（固件侧保险，`遥控超时` 灯会亮）
- 空格 / 急停按钮 → 发 `E`，主控停一切并锁定，必须再点「接管遥控」或「交还自动」才能退出

## 改参数

参数表里**双击「值」那一列**改数字，回车下发。

主控收到后会回一条 `K` 确认，表格里那个格子**闪一下绿**并显示主控里的真实值。
如果你填的数超出范围，主控会钳到边界再回读——**所以格子里显示的永远是真值**，
不会出现"以为改了其实没生效"。

常用的两个：

- `SPD_TARGET`（默认 11）：车太慢就调大，太冲就调小。这就是全车唯一的速度旋钮
- `SPD_STEP`（默认 1）：起步的加速快慢。调大起步猛、容易过冲；调小起步肉

参数都是 **int32 定点**（F103 没有 FPU）。带 ×100 的，想要 1.00 就填 `100`。

## 记录数据

勾「记录 CSV」→ 选保存位置 → 之后每一帧遥测都写进去，字段名见表头。
存一段阶跃响应，事后画图写报告用。

## 不接上位机也能测

用 XCOM 之类的串口助手，**勾上「发送新行」**，直接粘这些整行：

| 做什么 | 整行 |
|---|---|
| 直行 | `N,01*63` |
| 刹车 | `N,00*62` |
| 左移 | `N,02*60` |
| 右移 | `N,03*61` |
| 左转 | `N,04*66` |
| 右转 | `N,05*67` |
| 心跳 | `H*48` |
| 读全部参数 | `Q*51` |
| 急停 | `E*45` |

只发一条车会**只动 200 ms 就停**，那是心跳保险，正常。要一直走就每 200 ms 内补一条。
